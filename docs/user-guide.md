# Lexar 翻译插件 · 操作指引

> 适用读者：品牌部/设计部同事（零基础可上手）
> 一句话：这是一个装在 MasterGo 里的 Lexar 定制 AI 翻译工具——选中设计稿，点几下，20 个语种翻译+校对+合规检查+字体替换一次完成。

**支持语种（20 个）**：英语、简体中文、繁体中文、日语、韩语、德语、法语、西班牙语、意大利语、波兰语、荷兰语、瑞典语、葡萄牙语、巴西葡语、土耳其语、俄语、越南语、泰语、印尼语、阿拉伯语

**翻译方向**：不止英文→小语种——**20 个语种任意互翻**：
- 简体中文 → 繁体中文（简繁转换，台湾市场物料快速出稿）
- 英文 → 其他 18 个小语种（日常主力场景）
- 任意语种互翻（如德语稿 → 法语、葡语稿 → 西语，区域物料二次利用）

## 〇、为什么用它，而不是豆包等通用 AI 翻译？

| | 通用 AI 翻译 | 本插件 |
|---|---|---|
| 产品名/术语 | 每次翻得可能不一样 | **公司钦定术语库锁定，全批次统一；且术语库可持续扩展（新品自动识别入库/CSV 导入导出），越用越准** |
| 数字/规格 | 可能被「自由发挥」 | **代码级校验，逐字保留** |
| 翻译腔 | 机翻味重 | **去机翻感优化，像母语原创** |
| 违禁词 | 不检查 | **京东/亚马逊词表自动检测规避** |
| 源稿错别字 | 照翻不误，错误扩散到全语种 | **疑似拼写错误自动报警，保留原形提示核对** |
| 翻完怎么办 | 自己复制粘贴 | **一键写回画布+自动换字体** |
| 需要人工介入 | 机器翻到底，人工插不上手 | **CSV 导出/导入人工兜底：AI 译文导出给人工审校，改完导回画布自动同步** |
| 翻漏了 | 没人知道 | **强制拦截，不处理不能应用** |

## 一、5 分钟快速上手

> 只需 4 步，完成一张设计稿的多语种翻译。

**第 1 步：打开插件**

在 MasterGo 中打开设计稿 → 插件菜单中打开「Lexar 翻译」。

`[截图：插件入口位置]`

**第 2 步：扫描文本**

点击「当前页扫描」（或先选中图层，点「选中对象扫描」）。插件会自动采集所有文本并合并重复内容。

`[截图：扫描按钮与扫描结果列表]`

**第 3 步：翻译**

在语言下拉框选择目标语言（如「德语」）→ 点击「翻译」按钮 → 等待进度条完成。

`[截图：语言选择与翻译按钮]`

**第 4 步：应用**

确认译文无误后，点击「应用翻译」→ 译文自动写回画布，字体自动替换为目标语系字体。

`[截图：应用按钮与应用后的画布对比]`

✅ 到此完成。如果要翻多个语种，切换语言重复第 3-4 步即可。

> ⚠️ **新用户最常踩的坎**：如果「应用翻译」按钮是灰的，说明有待处理项（翻译失败/漏翻/占位符残留）没处理完——展开顶部黄色警告条，逐条点「重翻」或「知道了」处理后按钮即可用。

## 三、功能详解

> 每个功能都标注它解决什么实际问题。带 🤖 的是插件自动完成的能力（无需操作），带 👆 的是界面操作。

### 3.1 扫描与定位

- 👆 **当前页扫描**：采集当前页面全部文本节点，进度实时显示「扫描中(N)...」，单次上限 1500 节点
- 👆 **选中对象扫描**：只翻选中的图层（适合局部修改）；画布中选图层后按钮自动激活并显示选中数
- 🤖 **自动合并**：相同内容的多个节点合并为一条，翻译一次全部生效——解决「同一句话重复翻、译法不一致」
- 👆 **双击卡片快速定位**：双击条目卡片，画布自动跳转并选中对应文字位置；合并条目会在多个节点间循环定位——解决「几十条译文里找不到这条在画面哪儿」

### 3.2 翻译

- 👆 点击「翻译」批量并发调用 AI，通常 1-2 分钟完成一页；过程中出现统一进度条，可随时**取消**
- 🤖 **产品名/术语自动锁定**：命中术语库的内容直接使用公司钦定译法——解决「同一产品名每次翻得不一样」
- 🤖 **新产品名自动识别**：术语库没有的新品名，按命名规则自动生成 20 语种译名并弹「新品名待确认」，确认后自动入库——解决「新品上市术语库跟不上」
- 🤖 **第三方品牌/型号保护**：iPhone/GoPro/DJI/Switch 等 119 条第三方词条任何语言都不翻、不加前缀——解决「兼容性列表里的型号被直译」
- 🤖 **数字/规格逐字保留**：速度、容量、型号、版本号代码级校验——解决「900MB/s 被翻成『九百兆每秒』」
- 🤖 **翻译缓存**：相同文本再次翻译直接复用，不重复调用、不重复计费
- 🤖 **疑似错词保留**：源稿错别字不猜不音译，标「疑似拼写错误」提示核对——解决「错词被音译成诡异词直接上线」
- 🤖 **单位本地化**：存储单位按目标市场书写习惯自动调整（如法语区 TB→To、德语千分位）
- 👆 **源语言选择**：默认自动检测（支持中英等混排），也可手动指定

### 3.3 单条操作（每张卡片三个按钮）

- 👆 **定位**：画布跳转到该文字位置（同双击卡片）
- 👆 **重翻**：对该条单独重新翻译（源稿改过后/译文不满意时用）
- 👆 **应用**：只把这一条写回画布（配合「恢复原文」可逐条核对效果）
- 👆 **译文直接编辑**：译文框可手动修改；修改符合术语形态时会自动建议收入术语库——解决「人工审校的更优译法无法沉淀」
- 批量失败时顶部出现「重翻失败 (N)」按钮，一键重试全部失败条目

### 3.4 AI 校对（建议开启，默认开）

- 👆 点击「AI 校对」做五项检查：完整性、语义、漏翻、语法、**跨条目术语一致性**——解决「小语种没人有能力校对」
- 🤖 修正条目标绿色「校正」徽章，可逐条「恢复原译文」
- 🤖 **违禁词自动规避**：译文命中平台违禁词时自动改写规避并消除徽章——解决「被平台拦截才知道」

### 3.5 AI 润色（去机翻感，de/es/ru/tr 默认开）

- 🤖 面向德/西/俄/土耳其语的翻译腔优化，「当地消费者人设」判定是否需要润色——解决「译文正确但一眼看出是机翻」
- 🤖 硬约束兜底：数字/术语/规格被改动自动回退，不会改出事实错误
- 其他语种默认关闭，可在配置中手动开启

### 3.6 应用与撤销

- 👆 **应用翻译**：全部译文写回画布（有未处理异常时按钮禁用，先处理待确认项）
- 👆 **恢复原文**：一键把本插件应用的译文全部恢复为原文；**手动改过的节点自动跳过**——解决「撤销时把自己改的内容也冲掉」

### 3.7 字体自动替换

- 🤖 应用译文时按目标语系自动匹配字体（拉丁/西里尔/阿拉伯/泰/日韩/简繁）——解决「逐语系人工换字体，小时级工作量」
- 🤖 Avenir 字体的 ® 符号渲染异常自动修复
- 👆 **字体映射卡手动调整**：高级区「字体映射」中，每种源字体对应一张映射卡——可逐张手动选择目标字体；**选择后字号/行高/字距自动保持源值**，不会换字体后字号突然变大（解决「手动换字体后版式崩掉」）；调整后在映射卡上点「应用」单独生效，也可随批量「应用翻译」一起生效

`[截图：字体映射卡区域]`

### 3.8 产品线 / 场景 / 风格（高级区）

- 🤖 **产品线自动识别**：电竞/影像/消费级等 8 大产品线自动匹配对应语感与营销词——解决「电竞内存和存储卡用同一种语气翻」；也可手动指定
- 👆 **场景预设**：电商详情/技术文档/包装/UI/合规声明/操作指南 6 大场景一键切换——解决「包装、UI、说明书要另想办法翻」
- 👆 **风格预设**：标准/营销/专业等风格可选，也可自定义风格描述

### 3.9 术语库（高级区）

- 🤖 **产品名库**：140 条官方产品名，20 语种钦定译法（只读）
- 👆 **专属术语库**：189 条业务术语，可导入/导出 CSV 维护
- 🤖 **内置第三方词条**：119 条第三方品牌/型号，代码内置不可删
- 🤖 **自动入库**：校对修正/手动编辑的词条符合术语形态自动收入专属库；整句/营销文案自动拦截——解决「术语库越用越准」且「整句被锁死」的事故不会发生

### 3.10 CSV 导出/导入（人工兜底接口）

- 👆 **导出 CSV**：当前翻译结果导出（一条记录一行，Excel 打开不错位）——可交给人工翻译/审校修改
- 👆 **导入 CSV**：改完的 CSV 重新导入，画布内容同步更新，变动条目高亮标记——解决「AI 与人工翻译在同一管线协作」

### 3.11 诊断日志（高级区）

- 🤖 扫描/翻译/校对/应用每步自动留痕，插件崩溃或关闭重开后日志自动恢复不丢
- 👆 「复制日志」按钮一键复制（不可用时自动全选，Ctrl+C 即可）——**遇到 bug 复制日志反馈到设计部**

### 3.12 其他细节

- 🤖 **深色模式**：跟随系统自动切换
- 🤖 **多行文本格**：译文按源文换行位置还原（个别超长语种可能需微调框高）
- 🤖 **配置跨客户端同步**：API 配置/开关保存后团队共享，换电脑不用重配

## 四、徽章与提示速查（遇到问题查这里）

| 徽章/提示 | 含义 | 怎么办 |
|---|---|---|
| ⚠ 源文违禁词 | 源稿含平台违禁词（京东/亚马逊） | 提醒文案侧修改；不影响翻译 |
| ⚠ 译文违禁词 | 译文含目标市场违禁词 | 点「去校对规避」自动改写；或手动编辑 |
| ⚠ 术语库违禁词 | 译文是术语库官方值，含违禁词 | 只提示不改写（官方值优先）；知情即可 |
| 疑似拼写错误 | 源稿疑似错别字 | 核对源稿：确认无误点「确认保留源文」，有错先改源稿 |
| ⚠️ 漏翻 | 该条未成功翻译 | 点「重翻」；多次失败检查网络或联系管理员 |
| 翻译失败 | AI 调用失败 | 点「重翻失败」批量重试 |
| 占位符 | 译文中残留技术占位符 | 点「一键修复占位符」或重翻 |
| 新品名待确认 | 检测到术语库外的新产品名 | 「确认入库」（推荐）或「应用但不入库」 |
| 校正（绿） | AI 校对修改过 | 检查修改是否合理，可「恢复原译文」 |
| 导入变更 | CSV 导入改动了该条 | 知情即可 |

**待处理面板规则**：红色类（失败/占位符/漏翻）必须处理完才能批量应用；黄色/绿色类为提示，不阻塞。

## 五、常见问题（FAQ）

**Q1：为什么这条文本没有被翻译？**
A：通常是三种情况：① 它是型号/单位/纯数字，按规则本就不翻（如「512GB」「MB/s」）；② 它命中术语库 identity 词条（如第三方品牌名），全语种保留原文；③ 源语言和目标语言相同。这些都是正常行为。

**Q2：翻译结果和我想的不一样，可以改吗？**
A：可以。译文框直接编辑即可。如果你的修改是「更好的术语译法」，系统会自动建议收入术语库（下次同类内容自动用你的译法）。

**Q3：「待确认」里有条目，但「应用翻译」按钮是灰的？**
A：有红色阻塞类条目（翻译失败/占位符/漏翻）未处理。逐条点「重翻」或「知道了」或「编辑」处理完后，按钮恢复可用。

**Q4：翻错了能上画布吗？能撤吗？**
A：点「恢复原文」可整体撤销；你自己手动在画布上改过的文本不会被撤销覆盖，安全。

**Q5：违禁词徽章一直亮着，点「去校对规避」也没用？**
A：如果徽章是描边的「⚠ 术语库违禁词」，说明译文是术语库官方钦定值（如「有限终身质保」），按公司策略只提示不改写——这是正常的，知情即可。

**Q6：同一句话在不同地方翻得不一样？**
A：正常情况下术语库锁定的内容全篇统一。若发现非术语内容前后不一致，可点「AI 校对」——校对的 CHECK 5 专门检查跨条目术语一致性。

**Q7：源稿里有错别字怎么办？**
A：插件会标「疑似拼写错误」并保留原形不猜译。请先在 MasterGo 里改源稿，然后重新扫描翻译（或对该条「重翻」）。

**Q8：润色是什么？为什么有的语言有有的没有？**
A：润色是去机翻感优化。当前默认对机翻感较重的 4 个语种（德/西/俄/土）开启，其余语种译文质量已达标默认关闭（可在配置中手动开）。

**Q9：插件里的术语库会被我弄坏吗？**
A：不会。产品名库只读；专属库可编辑但有守卫（整句/乱码会被拦截）；内置第三方词条在代码里，删 CSV 也删不掉它。最坏情况：导出 CSV 备份 → 随便折腾 → 不行就导入恢复。

**Q10：插件在哪能看到它「干了什么」？**
A：高级区有诊断日志面板，扫描/翻译/校对/应用的每一步都有记录。遇到 bug 或任何异常，**复制诊断日志内容反馈到设计部**即可（日志面板有「复制日志」按钮；若复制按钮不可用，日志会自动全选，按 Ctrl+C 复制）。

## 六、使用小贴士

1. **先翻一个语种检查质量，再批量翻其他语种**——术语库和风格确认无误后，后续语种几乎不用管
2. **校对建议常开**（默认开）——它是违禁词自动规避的载体，关掉后违禁词只提醒不改写
3. **大改术语库前先导出 CSV 备份**——一键的事，防手滑
4. **多行文本格（含换行）的译文请留意换行位置**——插件会按源文换行位置还原，个别超长语种可能需要在画布上微调框高
5. **新品名翻译后记得处理「新品名待确认」**——确认入库后，下次全公司任何设计稿遇到该品名都会用统一译法
